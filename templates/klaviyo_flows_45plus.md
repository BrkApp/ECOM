# SEQUENCES EMAIL / SMS — AUDIENCE FEMMES 45+
**Plateforme :** Klaviyo (mais transposable Omnisend / Sendinblue / Brevo)
**Audience :** Femmes 45-70 ans francophones
**Principe :** ton chaleureux, jamais agressif, garanties repetees, langage clair.

---

## REGLES GENERALES (LIRE EN PREMIER)

1. **Pas d'emoji dans l'objet** (sauf 1 max, et plutot ❤️ ou 🌿). Les emojis "marketing" type 🔥💰⚡ flaguent comme jeune/spam pour cette audience.
2. **Police lisible** : 16px minimum sur desktop, 18px sur mobile. C'est non-negociable.
3. **Boutons gros** : 48px de haut, texte clair ("Voir mon panier", pas "Click here").
4. **Toujours rappeler** : la garantie 30 jours, le SAV francais, le paiement securise.
5. **SMS** : signe avec ton prenom (ex: "Sophie - [Marque]"). Beaucoup plus de retours.
6. **Horaires d'envoi** : 8h-11h ou 17h-20h. Eviter 12h-14h et apres 21h.

## SETUP KLAVIYO PAS-A-PAS

1. **Compte Klaviyo gratuit** (jusqu'a 250 contacts) : klaviyo.com
2. **Integration Shopify** : Klaviyo > Integrations > Shopify > Connect (1 clic)
3. **Liste "Newsletter"** : Lists > Create List > "Newsletter FR"
4. **Popup Klaviyo** sur Shopify :
   - Signup Forms > Create Form
   - Type : Popup
   - Trigger : exit-intent OR scroll 50%
   - Offre : -10% contre email
5. **SMS** :
   - Activer SMS dans Klaviyo (FR : ~0.06 EUR/SMS)
   - Acquerir le consentement SMS dans la popup (case a cocher SEPAREE de l'email)
6. **Importer les flows** : copie-colle les emails ci-dessus dans
   Flows > Create Flow > From Scratch.

## REVENU ATTENDU (regle 30%)
Pour une boutique mature, **30% du CA total doit venir des emails/SMS**.
Si tu es a 10%, tu laisses de l'argent sur la table.
